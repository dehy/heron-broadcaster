# M9 – Deck EQ

**Depends on:** M2

## Scope

- 10-band EQ per deck (bands listed in [Audio processing](../requirements.md#deck-eq)), ±12 dB.
- Presets (save, load, delete), enable / bypass.
- Smoothed parameter changes; UI sliders.

## Acceptance criteria

- [ ] Frequency response tests match expected curves.
- [ ] No clicks when moving sliders during playback.
